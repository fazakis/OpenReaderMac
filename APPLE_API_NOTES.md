# Apple API and permission verification

Inspected on macOS 26.0 (25A354), arm64, with Xcode 26.2 (17C52), Swift 6.2.3. The project deployment target is macOS 14.0. It uses SDK-available APIs and successfully compiles with that target. A physical macOS 14 machine was not available for runtime testing.

- **Screen capture:** ScreenCaptureKit `SCShareableContent`, targeted `SCContentFilter`, and `SCScreenshotManager.captureImage(contentFilter:configuration:)`. A capture occurs only after an explicit reading command. Screen Recording is checked before capture; the app includes a usage description and permission/relaunch recovery UI. Apple's guidance notes that a relaunch may be required after permission changes. [ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit) and [Capturing screen content in macOS](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos).
- **OCR:** `VNRecognizeTextRequest`, accurate recognition, runtime `supportedRecognitionLanguages()`, original strings and word/text positions. Unsupported requested languages are rejected, not silently replaced. [VNRecognizeTextRequest](https://developer.apple.com/documentation/vision/vnrecognizetextrequest).
- **Accessibility:** `AXIsProcessTrusted`, `AXUIElementCopyAttributeValue`, selected and visible character ranges, `AXStringForRange` and `AXBoundsForRange`. The app prompts using `AXIsProcessTrustedWithOptions`; it does not modify permission databases. Cross-app text operations run away from the main actor. [AXUIElementCopyAttributeValue](https://developer.apple.com/documentation/applicationservices/1462085-axuielementcopyattributevalue).
- **Copy fallback:** `AXUIElementPerformAction` invokes the enabled menu item whose command character is C and whose modifiers are `kAXMenuItemModifierNone` (Command is implicit). The installed SDK documents this modifier value as zero. A dedicated actor performs `NSPasteboard` snapshots and conditional restoration; ownership count and complete captured representations are compared. The API has no atomic cross-process compare-and-swap. No CGEvent keyboard injection, AppleScript, or Automation permission is used. [AXUIElementPerformAction](https://developer.apple.com/documentation/applicationservices/1462091-axuielementperformaction) and [NSPasteboard.changeCount](https://developer.apple.com/documentation/appkit/nspasteboard/changecount).
- **Playback:** `AVAudioEngine`, `AVAudioPlayerNode`, `.dataPlayedBack` completion callbacks, and `AVAudioUnitTimePitch`. The engine node allows local rate changes with separate pitch control; pitch remains zero. Word progression uses the audio sample clock and output/pitch-node latency, rather than a wall-clock timer pretending to be speech alignment. [AVAudioUnitTimePitch](https://developer.apple.com/documentation/avfaudio/avaudiounittimepitch) and [AVAudioPlayerNode scheduling](https://developer.apple.com/documentation/avfaudio/avaudioplayernode).
- **Transport:** no `NSAllowsArbitraryLoads` or arbitrary media exception. macOS 14 and later support IP-address exceptions in `NSExceptionDomains`; this app limits them to loopback. Application-level validation rejects public HTTP and credential-bearing URLs. [NSAllowsLocalNetworking / version-specific behavior](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsallowslocalnetworking) and [Preventing insecure network connections](https://developer.apple.com/documentation/security/preventing-insecure-network-connections).
- **First-run setup:** native SwiftUI `Window` and `openWindow`, with `dismissWindow(id:)` for Continue/Set up later. The installed SDK declares `OpenWindowAction` available from macOS 13 and `DismissWindowAction` from macOS 14, matching the deployment target. `AppStorage` persists the first visit; `NSApplication.didBecomeActiveNotification` refreshes permission status after returning from System Settings. [OpenWindowAction](https://developer.apple.com/documentation/swiftui/openwindowaction), [DismissWindowAction](https://developer.apple.com/documentation/swiftui/dismisswindowaction), and [application activation notification](https://developer.apple.com/documentation/appkit/nsapplication/didbecomeactivenotification).
- **Global shortcuts:** Carbon `RegisterEventHotKey`, registration return-code conflict reporting, no keyboard interception or input-monitoring event tap. Not every system-reserved combination is registerable. [Apple Developer Forums on RegisterEventHotKey restrictions](https://developer.apple.com/forums/thread/763878).

No private framework or undocumented screenshot API is used. The project is unsandboxed and ad-hoc signed for this local build; broader distribution requires appropriate Developer ID signing and notarization.
